# Desktop event monitoring

Observe bounded desktop-change notifications through X11 or Windows WinEvents.

Import `desktopevents` or `desktopevents.DesktopEvents`. The supported public entry points are listed in the [API contracts](api.md); platform backend modules are implementation details.
